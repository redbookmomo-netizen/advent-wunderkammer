# 黑森林 24 格机械降临节秘柜 · The Grand Advent Wunderkammer

专为手机竖屏（深度适配 **iPhone 18 Pro Max** 灵动岛安全区、`100dvh` 满屏无黑边、静音键模式外放与高刷丝滑交互）及桌面浏览器打造的 **3D 巴洛克胡桃木机械降临节奇珍柜（Mechanical Advent Cabinet & Automaton Clock）**。

在线打开地址（GitHub Pages）：
<https://redbookmomo-netizen.github.io/advent-wunderkammer/>

所有 3D 几何建模、程序化树瘤胡桃木细工镶嵌纹理、24 座独立微缩发条奇观、物理建模钢片音梳与木管风琴合成声场均打包在一个 `index.html` 中，**零外部图片、音频或 CDN 依赖**。

## 核心交互体验

- **错落中轴黄金比例 24 扇暗门与丝绒抽屉**：采用 `5 × 5` 巴洛克制表师对称中轴格局——正中央为双倍挑高的第 `XXIV (24)` 号平安夜双扇鎏金圣殿门，环绕 18 扇手绘树瘤胡桃木镶铜暗门与底层 5 只推拉式深红天鹅绒奇珍抽屉。
- **24 座绝不重样的 3D 动态发条奇观 + 《守柜人手记》**：推开任意小门或拉开抽屉，镜头将柔和推近至绒龛特写——从钟罩冰晶冬青玫瑰、举刀敬礼的胡桃夹子近卫锡兵、青金石浑天仪、威尼斯六骏旋转木马、环山蒸汽火车、金砂翻转沙漏、镂空陀飞轮怀表、跃出魔术礼帽的白瓷小兔，到双层螺钿旋转圣咏大祭坛；轻触龛内模型或点击机关按钮即可触发专属动作与机械声效，并可展开羊皮纸《黑森林守柜人冬夜手记》。
- **顶阁正点报时布谷鸟与吹号天使 + 黄铜松果重锤**：顶阁嵌有实时走时的窑烧珐琅罗马数字钟盘与青金石月相星盘；轻拉柜底悬垂的黄铜松果重锤（或点击「🔔 报时大机关」），顶阁双扇木门即刻弹开，机械布谷鸟振翅鸣唱、吹号天使滑出奏响圣咏。
- **「全开把玩模式 / 真实降临节日历锁」双模式切换**：默认开启守柜人全开把玩模式（亦支持一键「全柜盛开」欣赏 24 龛齐明奇观，或用「✨ 寻门」流萤光环指引下一格号码）；亦可一键切换至真实 12 月 1–24 日降临节日历锁。
- **「炉火雪夜 / 极光圣咏 / 晨曦金雾」三时辰氛围切换**：哥特格子窗外鹅毛大雪纷飞，室内斜洒呼吸丁达尔体积光束与浮动金尘。
- **瑞士钢片音梳 + 8' 木管风琴双声部物理合成**：内置八首古典圣诞与巴洛克复调曲目，兼容 iPhone 静音键模式外放；轻摇右侧象牙柄黄铜曲柄亦可即时换曲。

## 本地重新构建

`index.html` 已预打包为 100% 自包含单文件版本。如需修改 `src/` 源码后重新构建：

```bash
npm install
node build.mjs
```
