# 黑森林 24 格机械降临节秘柜 · The Grand Advent Wunderkammer (3D Spatial Edition)

专为手机触屏（深度适配 **iPhone 18 Pro Max** 灵动岛安全区、`100dvh` 满屏、静音键模式外放与 `360°` 掌心把玩）及桌面浏览器打造的 **3D 空间立体胡桃木雕机械降临节奇珍柜**。

在线打开地址（GitHub Pages）：
<https://redbookmomo-netizen.github.io/advent-wunderkammer/>

## 核心空间交互体验（零弹窗卡片 · 纯 3D 掌心把玩）

- **真 3D 多重景深木雕柜体与冬夜书房**：将巴洛克黑森林木雕原画与深度浮雕凹凸置换（Displacement & Bump Relief）、`0.72m` 实木侧壁、覆雪斜坡屋檐、前置垂摆松果重锤、`24` 座 `0.46m` 深槽木龛与远景飘雪花窗/噼啪石壁炉分离至真实 Three.js 3D 空间；单指滑动即可环绕感受浓郁立体视差，双指捏合可自由推近端详。
- **24 扇异形立体浮雕金门**：涵盖哥特尖拱门、半圆花房拱门、第 `15` 号椭圆形海图门与第 `24` 号正中双扇对开圣殿门，每扇木门均具真实木板厚度与合页开合动效。
- **推门靠近 · 亲手取出奇珍匣 360° 旋转把玩**：
  - 轻点任意木门，门扉旋开、镜头平滑推近木龛，龛内的 **3D 鎏金胡桃木水晶奇珍匣（Reliquary Box）** 会物理飞出木洞、悬浮至掌心；
  - **单指拖动可 360° 任意角度倾斜翻转**：透过表面折射高光水晶玻璃，匣内多层景深画面、实时动态光影粒子（蓝蝶振翅、彗星划落、热可可白雾、双拍跳动的琉璃机械之心、双螺旋星砂等）随角度呈现立体视差；
  - **拧动右侧 3D 黄金发条钥匙**：轻触匣侧旋转金钥匙（或点「🔑 拧动发条」）即可上弦唤醒高光星尘与专属机械声效；
  - **翻转至背面品读镌刻铭牌**：将奇珍匣在手中翻过 `180°`（或点「🔄 翻看背面铭牌」），即可阅读四颗铜铆钉固定在胡桃木匣背上的羊皮纸《黑森林守柜人冬夜博物手记》，点击背景木柜即可将奇珍匣平滑放回原木龛。
- **屋檐原生黄铜拨钮与双音布谷鸟报时**：原画屋檐下的 `Follow Real Date` 与 `Keeper's Open-All Mode` 立体铜拨珠均可直接在 3D 柜体上拨动；拉动两侧立体松果重锤即可唤醒顶阁木雕布谷鸟探身鸣唱与八首瑞士钢片音梳古典名曲。
