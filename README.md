# 黑森林 24 格机械降临节秘柜 · The Grand Advent Wunderkammer

双版本典藏仓库——同时完整保留 **「第一版 · 原画精雕典藏版」** 与 **「第二版 · Three.js 3D 空间掌心把玩版」**，并支持在两个版本底部控制栏一键互跳：

1. 🖼️ **第一版 · 原画精雕典藏版（默认首页 `index.html`）**  
   线上直达：<https://redbookmomo-netizen.github.io/advent-wunderkammer/>  
   以 1086 × 1448 高清巴洛克原画秘柜与 24 幅 768 × 1024 定制内龛插画呈现，支持 24 扇合页浮雕门开关、双指自由缩放平移、冬夜飘雪与壁炉流萤环境光效、8 首瑞士钢片音梳与木管风琴复调名曲，以及点开高清琉璃展柜卡片品读《黑森林守柜人冬夜博物手记》。

2. 🧊 **第二版 · 3D 空间掌心把玩版（独立页面 `spatial3d.html`）**  
   线上直达：<https://redbookmomo-netizen.github.io/advent-wunderkammer/spatial3d.html>  
   基于 Three.js 构建 1.02 米深雕花胡桃木镶铜立体秘柜与三层景深冬夜厅堂，推门后镜头推近将 3D 奇珍玻璃铜匣亲手取出悬浮于掌心，支持 360° 自由翻转、拧动右侧黄金发条钥匙、翻转 180° 阅读背面铆钉羊皮纸手记铭牌，以及「放回关门」自动合门。

## 本地打包构建

```bash
npm install
node build.mjs
```

执行后将同时生成 `index.html`（原画第一版）与 `spatial3d.html`（3D 空间版）。
