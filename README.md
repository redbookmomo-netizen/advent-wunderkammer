# 黑森林 24 格机械降临节秘柜 · The Grand Advent Wunderkammer

专为手机触屏（深度适配 **iPhone 18 Pro Max** 灵动岛安全区、`100dvh` 满屏无黑边、静音键模式外放与双指无级缩放漫游）及桌面浏览器打造的 **实景巴洛克胡桃木雕机械降临节奇珍柜（Interactive Mechanical Advent Wunderkammer）**。

在线打开地址（GitHub Pages）：
<https://redbookmomo-netizen.github.io/advent-wunderkammer/>

## 核心特色

- **实景黑森林木雕原画与 24 扇异形 3D 铰链浮雕金门**：像素级提取原画上错落排布的 24 扇鎏金浮雕木门（涵盖哥特尖拱门、半圆花房拱门、第 `15` 号巴洛克椭圆形海图门与第 `24` 号正中双扇对开圣殿门），支持真实 3D 透视合页旋开与胡桃木门背细节。
- **屋檐原生黄铜铭牌实体拨钮**：原画右上角屋檐下的两块黄铜拨片开关（`Follow Real Date · Daily Unlock` 与 `Keeper's Open-All Mode`）均可直接在木雕柜体上「啪嗒」拨动，实时切换真实十二月降临节日历锁与全柜 24 门波浪盛开奇观。
- **24 座高清动态奇珍内龛 + 《黑森林守柜人冬夜博物手记》**：每一扇浮雕门后均嵌有专属定制插画与实时 Canvas 光学粒子动效——从钟罩冰晶冬青玫瑰、星月黄道轨仪、守夜白鸮、流光蓝蝶花房、满月银角白鹿、泥金本草古籍、胡桃夹子近卫官、十二足光芭蕾剧场、发条玩具工坊、法贝热蝴蝶宝匣、云端热气球、威尼斯运河木马、紫晶矿洞、鹦鹉螺珍珠母贝钟、瓶中三桅帆船、掠过彗星的观星望远镜、知更鸟邮局、热可可姜饼暖炉、六角水晶雪花天球、阿尔卑斯雪夜地球仪、极光冰湖白天鹅、双拍跳动的绯红琉璃机械之心、双螺旋流金星砂沙漏，直到第 `24` 号双钟齐鸣的平安夜鎏金玫瑰大圣堂。
- **全场景活态光影与布谷鸟报时**：左窗鹅毛大雪纷飞、右侧石砌壁炉烈火跃动火星升腾、壁炉架红烛与钟罩呼吸微光、罗马钟盘鎏金秒针实时扫秒；轻拉两侧木雕松果重锤或轻触顶部报时鸟，即可唤醒双音木管布谷鸟振翅欢唱。
- **瑞士钢片音梳 + 8' 木管风琴物理声学合成**：内置《糖梅仙子之舞》《平安夜》《钟声颂歌》《花之圆舞曲》《圣善夜》《巴赫：耶稣，世人仰望的喜悦》《绿袖子》《芦笛舞曲》八首古典复调名曲，零外部音频依赖，兼容 iPhone 静音键模式外放。
